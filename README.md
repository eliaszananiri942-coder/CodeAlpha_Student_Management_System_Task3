
# Student Management System

**Developed by Elias Zananiri**  
**CodeAlpha Internship - Task 3 (High Level)**

## 📋 Description

A menu-driven C program to manage student records with permanent file storage.

## ✨ Features

- ✅ Add new student records (with unique ID validation)
- ✅ Display all students
- ✅ Search student by ID
- ✅ Update student information
- ✅ Delete student records
- ✅ Data persistence using binary file handling

## 🛠 Technologies Used

- C Programming Language
- File Handling (binary files)
- Structures

## 📁 File Structure

```
Student_Management_System/
├── student_management.c   # Main source code
├── students.dat           # Database file (auto-created)
└── README.md              # Documentation
```

## 🚀 How to Compile & Run

### Compile:
```bash
gcc student_management.c -o student_management
```

### Run:
```bash
./student_management
```
